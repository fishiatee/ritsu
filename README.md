## Get up and running

[uv](https://docs.astral.sh/uv/getting-started/installation/) needs to be installed first.

* `git clone https://github.com/fishiatee/ritsu && cd ritsu`
* Copy `.env.example` to `.env`, then populate it with appropriate values
* `uv sync --locked`
* `uv run main.py`
